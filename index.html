About me

RC

Full stack developer, start to finish

I've spent over eight years on every part of the software lifecycle: gathering requirements, designing services and databases, building the UI, writing the tests, and getting it all through CI/CD into production. Most of that work is Java and Spring Boot on the back end, Angular or React on the front end, and AWS underneath.

I like the parts of the job that make systems cheaper and calmer to run. At Fidelity I moved a legacy Java application to the cloud and cut its hosting costs in half, and I've tuned enough slow queries and bloated bundles to enjoy it. I also mentor junior developers and do a lot of code review.

Outside work I build small tools of my own, write fantasy fiction, and sketch designs for a myth-themed roguelite RPG.
