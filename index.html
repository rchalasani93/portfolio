About me

RC

Software engineer with a builder's habit

Coding is my day job, and most evenings it's also my hobby. I like taking an annoying manual task and turning it into a tool: a site that pulls every photo from a social profile, a save editor for a Pokémon ROM hack, a build setup that compiles a game from source.

I care about tools that work for real people, so I ship them where they're easiest to use. That usually means a hosted website, sometimes a browser extension, occasionally both.

When I'm not coding, I'm writing a fantasy action-adventure novel and sketching designs for a myth-themed roguelite RPG.
